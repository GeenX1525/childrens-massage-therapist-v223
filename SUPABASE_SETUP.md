# Настройка Supabase для сайта и админки

Ниже шаги, чтобы на GitHub Pages работали:
- админка `/admin.html` (вход по email/паролю)
- редактирование контента и правовых текстов
- загрузка фото на главной
- фиксация заявок со статусами

## 1) Создать проект Supabase

Создайте проект в Supabase и дождитесь окончания инициализации.

## 2) Применить SQL-схему

Откройте **SQL Editor** и выполните содержимое файла `supabase/schema.sql`.

## 3) Создать bucket для фото

Storage → **Create bucket**

- **Name:** `site-assets` (имя должно совпадать с кодом, если не задаёте своё — см. ниже)
- **Public bucket:** **ON** (обязательно, иначе картинки на сайте не откроются по прямой ссылке)

После создания bucket выполните политики из `supabase/schema.sql` (раздел Storage policies), если ещё не применяли весь файл.

Если вы назвали bucket иначе (например `public-assets`), в `supabase-config.js` добавьте:

```js
window.SUPABASE_STORAGE_BUCKET = "public-assets";
```

> В `schema.sql` политики привязаны к `bucket_id = 'site-assets'`. При другом имени bucket создайте аналогичные политики в SQL Editor для вашего имени или переименуйте bucket в `site-assets`.

## 4) Создать админов (2 пользователя)

Authentication → Users → **Add user**
- `oxanadavidova86@gmail.com` (пароль задайте в Supabase)
- `geenvx@gmail.com` (пароль задайте в Supabase)

Важно: **не храните пароли в репозитории** (он публичный). Пароли задаются только в панели Supabase.

## 5) Добавить публичный конфиг в проект (URL + anon key)

В Supabase: Project Settings → **API**
- `Project URL`
- `anon public`

Откройте файл `supabase-config.js` и вставьте значения.

Это **публичный** конфиг (URL + anon key), он нужен сайту на GitHub Pages и может храниться в репозитории.

## 6) Проверка

Откройте сайт локально через сервер (например Live Server), чтобы `supabase-config.js` корректно подгружался.

- `index.html`: отправка заявки должна открыть окно согласия и после подтверждения записать заявку в Supabase
- `admin.html`: вход под админом, затем:
  - вкладка “Тексты сайта” показывает JSON и даёт сохранить
  - “152‑ФЗ” позволяет редактировать текст политики и согласия
  - “Фото” загружает файл и обновляет `hero_image_url` в контенте
  - “Заявки” показывает список и даёт менять статус/фиксировать исполнение
