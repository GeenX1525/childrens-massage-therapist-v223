# Детский массажист Оксана — лендинг

Небольшой приветственный лендинг с формой записи + админка (Supabase).

## Как запустить

Это статический сайт. Можно открыть файл `index.html` двойным кликом.

Если нужен локальный сервер (чтобы всё работало одинаково в разных браузерах), варианты:

- **VS Code**: расширение *Live Server* → `Go Live`
- **Python (если установлен)**:

```bash
python -m http.server 5173
```

Откройте в браузере `http://localhost:5173`.

## Что внутри

- `index.html` — страница лендинга
- `styles.css` — стили
- `script.js` — форма + согласие 152‑ФЗ + отправка заявок в Supabase + подгрузка контента/правовых текстов
- `Oxana.jpg` — фото для hero-блока
- `Код.md` — исходник, который был взят за основу
- `admin.html` — админка (вход, заявки, контент, правовые тексты, фото)
- `admin.js`, `admin.css` — логика и стили админки
- `supabase/schema.sql` — схема БД/политики RLS
- `SUPABASE_SETUP.md` — пошаговая настройка Supabase
- `supabase-config.js` — публичный конфиг Supabase (URL + anon key)

## Примечание про заявки

Заявки сохраняются в Supabase и доступны в админке со статусами и датами.
